# Big Data on Google Cloud Platform

This repository contains the notes, tutorials, and code I've developed for working with Big Data technologies on GCP. It covers everything from basic cloud setup to data processing with Hadoop, Spark, and BigQuery.

## Tech Stack

- GCP (Compute Engine, Dataproc)
- MariaDB, Hive, BigQuery
- Hadoop (HDFS, MapReduce), Spark (PySpark)
- SQL and Python
- BigQuery ML and Vertex AI

## Project Structure

The repository is organized by technology:

### Intro to Cloud
- GCP and MariaDB Setup: How to create a project, set up a VM, and install MariaDB.
- Employee DB Queries: SQL exercises using a sample database.
- Challenge Answers: Solutions to the MariaDB practice problems.

### Hadoop
- Dataproc and HDFS: Instructions for setting up a cluster and using basic HDFS commands.
- MapReduce: Concepts and diagrams explaining how MapReduce works.
- Run MapReduce on Dataproc: How to execute Python-based MapReduce jobs on a live cluster.
- Scripts: Python code for the mapper and reducer functions.

### Hive
- Hive Tutorial: A guide to managing tables, partitions, and datasets in Hive.
